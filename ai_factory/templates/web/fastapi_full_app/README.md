# fastapi_full_app (universal)
Universal multi-route FastAPI + Jinja2 + SQLite skeleton for the AI Factory Builder.
This template is not app-specific — it serves as the base structure for any dynamic FastAPI app with multiple routes and database logic.

Placeholders replaced by the Builder:
  __APP_NAME__, __MODEL_NAME__, __TABLE_NAME__,
  __FIELDS_SQL__, __FORM_FIELDS_HTML__, __LIST_HEADERS__,
  __LIST_ROWS_HTML__, __SUMMARY_LOGIC_PY__,
  __FORM_ARGS__, __COLUMN_NAMES__, __PLACEHOLDERS__, __COLUMN_VALUES_LIST__
