Title: v3.2.6 — Auto‑Launcher & Graceful Shutdown

Summary
- Adds PowerShell auto‑launcher for unified Ollama + AI Factory.
- Starts Ollama daemon, waits for readiness, launches Uvicorn, verifies /advisor/trio_health, and handles graceful shutdown.

Files
- scripts/start_ai_factory.ps1

Usage
1. Optional: allow script execution for this session only:
   - Run in an elevated PowerShell: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`
2. Unblock the script if it was downloaded: `Unblock-File .\scripts\start_ai_factory.ps1`
3. Launch: `pwsh -File .\scripts\start_ai_factory.ps1`

Notes
- PowerShell does not require chmod +x, but Windows may block scripts from the internet. Use Unblock-File.
- The script auto‑kills previous Ollama processes, starts the daemon, then starts Uvicorn from the repo venv.
- Health verification: GET /api/version for Ollama, then GET http://127.0.0.1:8000/advisor/trio_health; prints ✅ when all three are healthy.
- Closing the window or Ctrl+C triggers cleanup of both processes.

Validation
- After startup, run: `pytest -q tests/test_advisor_trio_health_endpoint.py`
- Expected: 1 test passes, trio shows strategist/memory/executor.

- VERSION bumped to v3.2.6-auto-launcher
