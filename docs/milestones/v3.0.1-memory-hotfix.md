Title: v3.0.1 Memory Dashboard Hotfix

Issue
- Visiting `/dashboard/memory?q=` could raise 500 due to null or malformed `tags`.

Fixes
- Normalize `tags` and `summary` in `ai_factory/ui/memory_ui_router.py` before rendering.
- Template safeguards for tag rendering in `memory_card.html` and `index.html`.
- Added `safe_tags()` helper in `ai_factory/memory/memory_agent.py`.
- Added safety test `tests/test_memory_ui_safety.py`.

Verification
- Open `/dashboard/memory?q=fastapi` and `/dashboard/memory?q=failed` – pages load without crashes; entries with missing tags show “no tags”.
