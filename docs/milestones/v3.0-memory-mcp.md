Title: Phase 3.0 – Cognitive Memory MCP (Local)

Overview
- Adds local long‑term memory with search, recall, and learning.
- Fully local: SQLite under `ai_factory/data/` and files under `ai_factory/data/logs`.
- Integrates with Planner, Evaluator, Orchestrator, and Dashboard (Memory tab).

Schema (SQLite: ai_factory/data/memory.db)
- memory_entries: id PK, run_id, goal, summary (1–3 paras), tags (comma), score, created_at ISO8601, deleted (soft delete flag)
- memory_links: id PK, source_run, target_run, reason, created_at
- memory_feedback: id PK, run_id, rating (+1/‑1), notes, created_at

Endpoints (tag: Memory)
- POST `/memory/store` → {id}
- GET `/memory/search?q=&limit=20` → results list (id, run_id, goal, summary, tags, score, created_at)
- GET `/memory/recall/{run_id}` → related memories
- POST `/memory/learn` → summarize runs and store; auto‑link by tag overlap; returns {added, linked}
- GET `/memory/stats` → { total, recent_7d, avg_score, tags[], last_created_at }
- DELETE `/memory/{id}` → soft delete

Planner/Evaluator Integration
- Planner queries top memories for goal keywords; attaches memory_context to plan.
- Evaluator stores summary/tags/score after runs; optional learn batch.

Dashboard Usage
- Visit `/dashboard/memory` for search/stats and memory cards.
- Click a card to open `/dashboard/memory/{id}` with details and related runs.

Verification Steps
1) Start: `uvicorn ai_factory.main:app --reload`
2) Run existing planner/evaluator flow to seed data.
3) POST `/memory/store` and `/memory/learn`; GET `/memory/search` and `/memory/recall/{run_id}`.
4) Open `/dashboard/memory?q=fastapi` and confirm rendering.
5) GET `/factory/info` shows version `v3.0-memory-mcp`, `memory_enabled: true`.
