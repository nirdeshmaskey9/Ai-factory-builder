# v3.9.4.1 — Stable Release

**Date**: 2025-11-12  
**Tag**: v3.9.4.1-nl  
**Phase**: 3.9.4.1

## Overview

This milestone represents the completion of Phase 3.9.x, delivering a stable, unified JoJo identity with persistent memory and clean hybrid output. All critical issues have been resolved, and the system is production-ready.

## Key Achievements

### ✅ Unified Identity
- Single, consistent JoJo persona (no mode switching)
- Identity layer integrated into all interactions
- Warm, intelligent, emotionally aware voice

### ✅ Persistent Memory
- Identity memories seeded on startup (idempotent)
- Memory persists across restarts (SQLite)
- Reliable recall of user information
- Debug endpoints for memory diagnostics

### ✅ Clean Hybrid Output
- No `[Local]`/`[External]` prefixes
- No memory IDs or chunk references
- No "User:" transcript spam
- No debug noise or internal logs

### ✅ Stable Pipeline
- Memory retrieval FIRST (before any model runs)
- External model OVERRIDES local (not merged)
- Clean output applied LAST
- Proper error handling and fallbacks

### ✅ Local Trio Optimized
- Strategist: Qwen 2 1.5B Instruct Q4 (~900 MB VRAM)
- Memory: Mistral 7B Instruct v0.3 Q4 (~4200 MB VRAM)
- Executor: Phi-3 Mini 3.8B Q4 (~2400 MB VRAM)
- Total: ~7.5 GB (within 8GB limit)

## Technical Improvements

### New Features
1. **Identity Seeder**: Automatic seeding of core identity memories
2. **Database Ping**: Connection verification on startup
3. **Memory Diagnostics**: Comprehensive diagnostic script
4. **Persistence Tests**: Full test coverage for memory system
