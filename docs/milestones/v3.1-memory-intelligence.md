Title: v3.1 – Memory Intelligence Expansion (Cognitive Resonance)

Highlights
- Auto-learning after successful runs (evaluator hook)
- Ranked semantic search and recall (semantic + tags + recency)
- Embedding support with fallback hashing
- Export/Import routes and files
- Dashboard insights, context preview, timeline pages
- Backup/Restore endpoints
- Diagnostics endpoint for ranking transparency

Ranking
- total = 0.6*semantic + 0.25*tag_overlap + 0.15*recency
- semantic: cosine between query and memory vectors
- tags: ratio of shared tokens in query and memory tags
- recency: 1/(1+days_since_created)

Embeddings
- Table: memory_embeddings(entry_id, vector, updated_at)
- If no OpenAI key, fallback to SHA256-based deterministic vector

Backup/Restore
- GET /memory/backup (ADMIN_MODE=true)
- POST /memory/restore (ADMIN_MODE=true)

Dashboard
- /dashboard/memory/insights (stats + learn button)
- /dashboard/memory/context/{run_id} (side preview)
- /dashboard/memory/timeline (timeline placeholder)
