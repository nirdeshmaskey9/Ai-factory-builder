# Phase 2.1 – Orchestrator & Supervisor Polish

This release adds retrieval, inspection, and summary endpoints to monitor orchestrator runs and prepare for Phase 3 (Cognitive Recall).

## Endpoints

- `GET /orchestrator/history?limit=10&status=success&sort=desc`
  - Returns recent orchestrator runs: `run_id, goal, status, score, attempt, duration_sec, timestamp, report_path, supervisor_report_path`.

- `GET /orchestrator/steps/{run_id}`
  - Returns all steps of a run from the `orchestrator_run_steps` table: `id, step_name, step_status, log_path, timestamp`.

- `GET /orchestrator/summary/{run_id}`
  - Merges run info, step list, and supervisor report JSON (if present). Includes `not_found: true` for missing artifacts.

- `GET /supervisor/report/{run_id}`
  - Returns the raw supervisor decision/report JSON saved during the run.

## Logging and Rotation

- Per-run reports are stored under `logs/orchestrator/run_<id>.json`.
- Per-run supervisor reports are stored under `logs/supervisor/report_<run_id>.json`.
- Startup performs simple log rotation: removes `logs/orchestrator/*` and `logs/supervisor/*` older than 30 days.

## Factory Info Enhancements

`GET /factory/info` now includes:
- `latest_run_id`
- `total_runs`
