# v2.4-control-center – AI Factory Control Center

This milestone delivers a real-time Control Center with analytics, feedback, websockets, search/export, and a dark-themed dashboard.

## Features

- Analytics API: `/analytics/stats`, `/analytics/trends`, `/analytics/system`
- Feedback API: `/feedback` (POST), `/feedback/{run_id}`, `/feedback/all`
- WebSockets: `/ws/runs` and `/ws/logs/{run_id}`
- Dashboard pages: `/dashboard`, `/dashboard/runs`, `/dashboard/summary/{id}`, `/dashboard/analytics`
- Exports: `/dashboard/runs?download=json|csv`
- Dark theme with Tailwind + custom CSS

## Verification

Start server:

uvicorn ai_factory.main:app --reload

Open:
- http://127.0.0.1:8000/dashboard
- http://127.0.0.1:8000/dashboard/runs
- http://127.0.0.1:8000/dashboard/analytics

APIs:
- curl http://127.0.0.1:8000/analytics/stats
- curl http://127.0.0.1:8000/analytics/trends
- curl -X POST http://127.0.0.1:8000/feedback -H "Content-Type: application/json" -d '{"run_id":1,"rating":"up","comment":"ok"}'

## Notes

- psutil is optional; `/analytics/system` returns `available: false` if missing.
- WebSockets degrade gracefully; polling also fills charts via `/analytics/*`.
