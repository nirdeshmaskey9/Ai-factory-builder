# Phase 2.2 – AI Factory Dashboard v1

Minimal in-app web dashboard to visualize builds, orchestrator runs, and summaries.

## Routes

- `GET /dashboard`
  - Renders overview with factory info and built apps list (from `builds/*/outputs/*`).
- `GET /dashboard/runs`
  - Shows recent orchestrator runs (limit 20), includes goal, status, score, duration, timestamp.
- `GET /dashboard/summary/{run_id}`
  - Displays merged summary (run + steps + supervisor report). Pretty-printed JSON included.
- `GET /dashboard/launch/{build_id}`
  - Spawns `python scripts/run_app.py --id <build_id>` in background; returns `{status:"launched"}`.

## Templates

Located under `ai_factory/ui/templates/dashboard` using `Jinja2Templates`:
- `layout.html` – Tailwind CSS navbar, shared layout.
- `index.html` – Factory info and builds list with Launch buttons.
- `runs.html` – Table of recent orchestrator runs.
- `summary.html` – Detailed summary, steps table, and raw JSON view.

## Integration

Router mounted in `ai_factory/main.py`:
```python
from ai_factory.ui.dashboard_router import router as dashboard_router
app.include_router(dashboard_router)
```
