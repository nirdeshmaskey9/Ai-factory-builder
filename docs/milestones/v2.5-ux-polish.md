% v2.5-ux-polish – UX Polish & Experience Upgrade

This release refines the Control Center with a live progress tracker, error insights, persistent filters, rerun actions, toasts, transitions, and dark theme touch-ups.

## Highlights
- Live Progress Bar updates via WebSocket on run summary
- Error Insight panel parses recent log lines for likely cause
- Persistent filters on runs page via localStorage
- "Rerun This Goal" button (+ toast feedback)
- Toast notifications for actions and exports
- Smooth transitions and loading states
- Dark theme polish (contrast, hover, shadows)

## Endpoints
- POST `/rerun/{run_id}` → re-executes the goal of a previous run

## Frontend
- `ui_helpers.js` (toast & helpers)
- `progress.js` (stage tracking)
- Components: progress_bar, error_insight, toast

## Verification
- Start: `uvicorn ai_factory.main:app --reload`
- Summary page shows progress and rerun button
- Failed runs display error insight
- Runs page filters persist between reloads
